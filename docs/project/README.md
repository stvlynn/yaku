# Project

Yaku is a WXT Manifest V3 browser extension for local bilingual translation. It runs HY-MT2-1.8B through Transformers.js in a dedicated worker owned by an offscreen extension document.

The repository started from the agentic-coding template. Its frontend follows FSD and centralizes UI copy and semantic styles. No backend is required for model inference or document processing.

See [architecture](architecture.md), [research](../research/README.md), and [validation](../quality/validation.md). The implementation and acceptance ledger distinguish delivered workflows from remaining reference-feature parity work.
